## Projetos em destaque

### Organizador — Aplicação web para gestão de tarefas

Projeto autoral desenvolvido com **Python 3.12 e Django**, estruturado como um monólito modular para organizar tarefas, rotinas recorrentes e espaços de trabalho compartilhados.

- Organização por aplicações Django, separando responsabilidades como contas, controle de acesso, espaços de trabalho, tarefas, agendamento, auditoria e dashboard.
- Modelagem de tarefas, recorrências, ocorrências datadas e atribuições individuais.
- Geração idempotente de ocorrências semanais, quinzenais e mensais, com prevenção de registros duplicados.
- Regras de autorização verificadas no servidor, considerando vínculo ativo e papel do usuário no espaço de trabalho.
- Registro de execução e histórico de alterações por meio de eventos de auditoria.
- Validação de anexos por tipo e tamanho, armazenamento com nomes aleatórios e download condicionado à autenticação e autorização.
- Persistência com PostgreSQL e SQLite; testes automatizados com **pytest/pytest-django** e padronização estática com **Ruff**.
- Integração contínua com verificações Django, conferência de migrações, testes, build Docker e smoke test do container.

A demonstração pública oferece acesso como visitante, dados de exemplo e operações de escrita bloqueadas. É um ambiente demonstrativo, não uma homologação para uso com dados reais. O README do projeto documenta o que está implementado, parcialmente implementado e planejado.

[**Código-fonte e documentação técnica**](https://github.com/CarolMaini/sistema-tarefas) · [**Demonstração**](https://organizador-demo.onrender.com)
